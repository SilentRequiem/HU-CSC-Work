# HU CSC Coursework Repository

This repository contains my coursework and projects completed as part of my Computer Science and Cyber Security studies at Hampton University.

It includes assignments, labs, and projects from multiple courses, showing my progression in programming, problem-solving, and core computer science concepts.

---

## Overview

The purpose of this repository is to document my academic work and track my growth as a developer. Each folder or file represents work completed in a specific course.

---

## Courses Included

### CSC 100 – Problem Solving in Computer Science  
Introduction to problem-solving techniques and basic programming concepts.

### CSC 120 – Introduction to Computers  
Fundamentals of computer systems, hardware, and software.

### CSC 151 – Computer Programming I  
Core programming concepts including variables, conditionals, loops, and basic data structures.

### CSC 152 – Computer Programming II  
Object-oriented programming, advanced problem solving, and deeper understanding of program structure.

### CSC 215 – Discrete Structures  
Mathematical foundations of computer science, including logic, sets, relations, and algorithms.

### CSC 251 – Data Structures I  
Implementation and analysis of data structures such as arrays, lists, stacks, and queues.

### CSC 291 – Swift Programming  
Introduction to iOS development using Swift and SwiftUI.

### CYS 323 – Ethics, Law, and Policy in Cyberspace  
Exploration of ethical, legal, and policy issues related to cybersecurity.
