# HU CSC Coursework Repository

This repository contains my coursework and projects completed as part of my Computer Science and Cyber Security studies at Hampton University.

It includes assignments, labs, and projects from multiple courses, showing my progression in programming, problem-solving, computer organization, data structures, software development, and cybersecurity.

---

## Overview

The purpose of this repository is to document my academic work and track my technical growth over time. Each main course folder represents coursework from a specific subject, while larger assignments and projects show how course concepts were applied in practice.

---

## Courses Included

### [CSC 100 – Problem Solving in Computer Science](./CSC%20100%2033)
Introduction to problem-solving techniques and basic programming concepts.

### [CSC 120 – Introduction to Computers](./CSC%20120%2034)
Fundamentals of computer systems, hardware, software, and general computing concepts.

### [CSC 151 – Computer Programming I](./CSC%20151%2002)
Core programming concepts including variables, conditionals, loops, methods, arrays, and introductory problem solving.

### [CSC 152 – Computer Programming II](./CSC%20152%2002)
Object-oriented programming, classes, inheritance, exceptions, file handling, and more advanced program structure.

### [CSC 204 – Computer Organization I](./CSC%20204%2001)
Introduction to computer organization and low-level data representation, including binary arithmetic, number systems, and how computer hardware represents and processes information.

### [CSC 215 – Discrete Structures](./CSC%20215%2002)
Mathematical foundations of computer science, including logic, sets, relations, functions, counting, and algorithmic reasoning.

### [CSC 251 – Data Structures I](./CSC%20251%2001)
Implementation and analysis of data structures and algorithms, including arrays, linked lists, stacks, queues, and algorithm analysis.

### [CSC 291 – Swift Programming](./CSC%20291%2002)
Introduction to iOS development using Swift and SwiftUI, including application interfaces, navigation, state management, and app logic.

### [CSC 395 – Advanced Swift App Development with ARKit](./CSC%20395%2002)
Advanced iOS development using SwiftUI, SwiftData, Core ML/Create ML, Vision, Natural Language, and ARKit/RealityKit.

### [CYS 323 – Ethics, Law, and Policy in Cyberspace](./CYS%20323%2001)
Exploration of ethical, legal, and policy issues related to cybersecurity and the use of technology in society.
